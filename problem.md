# Problem
Students often struggle to keep track of assignments, deadlines, and responsibilities across multiple courses. When they have several classes, it can be difficult to remember which assignments are due, prioritize their work, and keep track of what they have already completed. Missing deadlines or forgetting smaller assignments can affect their academic performance.

# Initial requirements
- R1: The app must run locally on the user's computer with one command, be accessible through a web browser, and must not require an API key, account, or paid service.
- R2: Users must be able to add new courses.
- R3: Users must be able to add assignments and give each assignment a title and description.
- R4: Users must be able to assign each assignment to a course.
- R5: Users must be able to set a due date for each assignment.
- R6: Users must be able to view all their assignments in one place.
- R7: Users must be able to mark assignments as completed.
- R8: Users must be able to edit and delete assignments.
- R9: The app must distinguish between completed and incomplete assignments.
- R10: The app must display upcoming and overdue assignments.
- R11: Assignment and course information must be saved locally so it remains available after closing and reopening the app.
